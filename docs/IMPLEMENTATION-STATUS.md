# وضعیت پیاده‌سازی

## پیاده‌سازی‌شده

- Migrationهای دامنه، Cache، Session و Queue
- مدل‌ها و Relationهای اصلی
- Spatie Permission Teams برای نقش‌های هر کارواش
- Super Admin مستقل با `is_super_admin`
- ورود Blade با رمز و OTP
- احراز هویت API با Sanctum
- دعوت و مدیریت اعضا
- خدمات و قیمت بر اساس نوع خودرو
- قوانین ظرفیت، استثنا و تولید اسلات
- ساخت رزرو با محاسبه قیمت Backend و Row Lock
- گردش وضعیت رزرو و آزادسازی ظرفیت
- ثبت پرداخت حضوری
- QR link و Scan tracking
- Controller و Route پنل ادمین، کارواش و API
- ایجاد و ویرایش کارواش از پنل مدیر کل
- Blade dashboard و صفحات مدیریت اصلی
- OpenAPI اولیه
- Factory و Feature Testهای پایه

## اتصال خارجی باقی‌مانده

- Adapter واقعی شرکت پیامک
- درگاه پرداخت آنلاین و Webhook
- آپلود لوگو و تصویر
- طراحی نهایی رابط کاربری
- پوشش تست جامع‌تر
- تنظیم Redis، Queue worker، Scheduler، Domain و SSL در سرور
