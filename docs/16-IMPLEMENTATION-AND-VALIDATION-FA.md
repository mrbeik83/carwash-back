# گزارش پیاده‌سازی و اعتبارسنجی

## محدوده انجام‌شده

- فارسی‌سازی پنل کارواش و پیام‌های اصلی
- تقویم شمسی برای ورودی و نمایش تاریخ
- بازطراحی داشبورد، سایدبار و هدر پنل
- زمان‌بندی هفتگی شنبه تا جمعه
- تولید اسلات ۳۰ یا ۶۰ دقیقه‌ای
- ظرفیت مستقل برای هر اسلات
- حفظ ظرفیت‌های دستی هنگام تولید مجدد
- استثناهای تعطیلی و ظرفیت ویژه
- تقویم هفتگی رزروها و فیلتر بر اساس اسلات
- رزرو سریع حضوری
- بهبود قرارداد API و پاسخ‌های استاندارد رزرو/خودرو
- سند اتصال فرانت و OpenAPI

## اعتبارسنجی‌های انجام‌شده در محیط تحویل

- PHP lint روی فایل‌های PHP تغییرکرده
- بررسی نحوی JavaScript با Node
- کامپایل نحوی تمام Bladeها با Blade Compiler
- بوت Laravel و بررسی ثبت routeهای جدید
- تست تبدیل رفت‌وبرگشت تاریخ میلادی و شمسی
- اسکن پنل برای ورودی native میلادی باقی‌مانده
- بررسی عدم وجود فایل `.env` در بسته نهایی

## محدودیت محیط اجرا

در محیط ساخت این خروجی، افزونه PDO مربوط به MySQL/SQLite و افزونه DOM در PHP نصب نبود؛ بنابراین اجرای migration واقعی و `view:cache` در همین محیط ممکن نشد. همچنین registry داخلی npm یکی از وابستگی‌ها را برنگرداند و build نهایی Vite در این محیط قابل تولید نبود.

این محدودیت به معنی خطای کد نیست، اما پیش از استقرار لازم است دستورات زیر روی محیط توسعه یا سرور دارای PHP extensions و دسترسی npm اجرا شوند:

```bash
composer install
npm ci
npm run build
php artisan migrate --force
php artisan optimize:clear
php artisan route:list
php artisan test
```

## تست پذیرش پیشنهادی

1. برای شنبه ساعت ۰۹:۰۰ تا ۱۱:۰۰ و فاصله ۳۰ دقیقه تعریف کنید.
2. ظرفیت اسلات‌ها را ۲، ۳، ۱ و ۴ قرار دهید.
3. برنامه را ذخیره و نمای اسلات واقعی را کنترل کنید.
4. یک ظرفیت را دستی تغییر دهید و برنامه هفتگی را دوباره ذخیره کنید؛ تغییر دستی باید باقی بماند.
5. برای یکی از تاریخ‌ها تعطیلی کامل ثبت کنید؛ اسلات‌های بدون رزرو آن روز باید بسته شوند.
6. از API availability همان هفته را بگیرید؛ فقط اسلات‌های باز و دارای ظرفیت باید برگردند.
7. دو درخواست هم‌زمان نزدیک ظرفیت نهایی ثبت کنید؛ تعداد رزرو نباید از ظرفیت عبور کند.
8. رزرو را لغو کنید؛ ظرفیت اسلات باید آزاد شود.
9. پنل را روی موبایل و دسکتاپ در حالت RTL بررسی کنید.
10. ورود OTP از دامنه فرانت واقعی و cookie session را کنترل کنید.
