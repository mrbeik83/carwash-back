# چک‌لیست تحویل فاز اول

## دسترسی

- [ ] Super Admin همه پنل را می‌بیند.
- [ ] مدیر یک کارواش به کارواش دیگر دسترسی ندارد.
- [ ] عضو تعلیق‌شده وارد پنل نمی‌شود.
- [ ] Permission تمام دکمه‌ها و Routeها را کنترل می‌کند.

## رزرو

- [ ] قیمت در Backend محاسبه می‌شود.
- [ ] رزرو بیش از ظرفیت ممکن نیست.
- [ ] لغو ظرفیت را آزاد می‌کند.
- [ ] تمام تغییر وضعیت‌ها History دارند.
- [ ] شماره پیگیری یکتا است.

## پنل کارواش

- [ ] پروفایل، تنظیمات، خدمات، زمان‌بندی، کارکنان و QR قابل مدیریت است.
- [ ] داشبورد آمار روز را نمایش می‌دهد.
- [ ] رزرو حضوری قابل ثبت است.
- [ ] پرداخت حضوری قابل ثبت است.

## API

- [ ] OTP rate limit دارد.
- [ ] CORS و Sanctum stateful صحیح است.
- [ ] پاسخ Validation یکپارچه است.
- [ ] OpenAPI با Frontend هماهنگ است.

## زیرساخت

- [ ] Queue worker فعال است.
- [ ] Scheduler فعال است.
- [ ] Backup دیتابیس تست شده است.
- [ ] APP_DEBUG=false است.
- [ ] Log و Error monitoring فعال است.
