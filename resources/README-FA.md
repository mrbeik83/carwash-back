# منابع بهینه‌شده پنل فارسی کارواش

این پوشه برای جایگزینی مستقیم پوشه `resources` پروژه آماده شده است.

## فایل‌های فونت موردنیاز

این دو فایل باید از بسته IRANYekanX(Pro) استخراج شده و دقیقاً در مسیر زیر باشند:

```text
public/fonts/iranyekanx/IRANYekanXVFaNumVF.woff2
public/fonts/iranyekanx/IRANYekanXVF.woff2
```

- فایل `IRANYekanXVFaNumVF.woff2` فونت اصلی رابط و دارای اعداد فارسی است.
- فایل `IRANYekanXVF.woff2` برای شماره موبایل، ایمیل، کد رزرو، IP و اطلاعات لاتین استفاده می‌شود.
- فایل ZIP فونت را مستقیماً داخل `public/fonts` قرار ندهید؛ خود فایل‌های `woff2` باید استخراج شده باشند.

## بعد از جایگزینی

```bash
php artisan optimize:clear
npm run build
```

در توسعه:

```bash
npm run dev
```

سپس مرورگر را با `Ctrl + F5` بازنشانی کنید.

## مهم‌ترین بهبودها

- ایران‌یکان متغیر با وزن‌های ۱۰۰ تا ۹۰۰
- اعداد فارسی برای رابط و فونت جدا برای داده‌های فنی
- preload فونت در تمام Layoutها
- تقویم شمسی بهتر با محدودیت min/max، کلید Escape و دسترس‌پذیری صفحه‌کلید
- تبدیل خودکار اعداد فارسی و عربی به انگلیسی هنگام ارسال شماره موبایل و مقادیر عددی
- فرم‌ها، دکمه‌ها و ناحیه لمس مناسب موبایل
- جدول‌های افقی و سرستون ثابت
- حالت تاریک، کاهش حرکت، چاپ و فوکوس قابل مشاهده
- تاریخ‌های شمسی در بخش‌های مدیریت کل
- برچسب فارسی وضعیت رزرو، پرداخت و روش پرداخت
